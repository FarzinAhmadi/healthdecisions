Maryland Hospital Global Budget Revenue Tracker

Maryland sets a fixed annual revenue budget for each hospital rather than paying per service. This tracker compiles what the state publishes about that system — regulated revenue, admissions, payer mix and margins — into one place you can search, filter and download.

Why this exists

Maryland has operated an all-payer hospital rate-setting system for decades, and moved to global budgets in 2014. Everything the tracker shows is already published by the Health Services Cost Review Commission — but it is spread across years of separate filings in formats that make comparison across hospitals or over time genuinely hard. The work here is parsing, reconciling and documenting that material so it can be used and cited without repeating the effort.

The question is timely beyond Maryland. Several states are moving toward hospital global budgeting on a model borrowed from Maryland's design, which makes twenty years of Maryland reporting the closest thing to evidence about how such a system behaves.

Using and citing the data

The dataset, data dictionary and source manifest are available from the tracker's Data tab, along with the code used to build it. If you use it in published work, please cite it; if you find an error, please tell us.
